# Quote Builder AI

> Instant, accurate service quotes from scope, parts and labor data.

Generates professional quotes in minutes using historical job data, live parts pricing and regional labor rates.

**Live:** https://ziontechgroup.com/quote-builder-ai/  
**Network hub:** https://github.com/Zion-support/zion-app-network

## Features
- Scope-to-quote generation with templates
- Live parts pricing via [spare-price-scout](https://github.com/Zion-support/spare-price-scout)
- Margin guardrails and approval workflows
- CRM-ready PDF and e-sign handoff
